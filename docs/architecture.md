# Организация фронтенда

Референс — только папка [Variant/app-new](https://github.com/heteraff1-tech/Variant/tree/main/app-new). За основу взяты её `pages`, `features/*/{model,ui}`, `shared/ui`, публичные `index.js` и отдельные `assets/styles/tokens`. Авторизация, router, API-клиент, Pinia и Query из Variant в этот проект не перенесены: работающий сценарий их не требует.

## Кто чем владеет

| Уровень              | Ответственность                                    | Пример                                                      |
| -------------------- | -------------------------------------------------- | ----------------------------------------------------------- |
| `pages`              | Раскладка и связывание возможностей                | `HomePage` соединяет экран показателей и помощника          |
| `features/*/model`   | Состояние, lifecycle, действия и подготовка данных | `useHealthScreen`, `useAssistant`, `useOnboardingFlow`      |
| `features/*/ui`      | Отображение props и передача событий               | `PressureCard`, `AssistantComposer`                         |
| `features/*/lib`     | Специализированный рендеринг                       | `PulseShape` строит SVG и не управляет сценарием онбординга |
| `features/*/config`  | Статические настройки и демоданные                 | Подсказки помощника, измерения для превью                   |
| `shared/ui`          | Общий визуальный контракт                          | `UiButton`, `UiInput`, `UiMetricCard`, `UiBottomSheet`      |
| `shared/composables` | Поведение без знания конкретной страницы           | Масштабирование, параллакс, жест сворачивания               |
| `shared/lib`         | Общие функции                                      | Чтение длительностей из CSS, easing                         |

Референс проверен на коммите `9c87f6feb6e34a7be7a02dc35ecadefc01577223`; изучались только файлы `app-new`.

Внешний код подключает feature через её `index.js`. Внутри feature используются относительные импорты. `shared` не импортирует страницы или features. Общий контрол не знает про Анну, помощника или медицинские данные.

## Компоненты и стили

SFC оформляется в порядке `template → script setup → style`. Компонент подключает собственный файл:

```vue
<style scoped lang="scss" src="@/assets/styles/components/button.scss"></style>
```

Глобальный `main.scss` загружает только основы и токены. Стили страницы отвечают за расположение её непосредственных блоков. Кнопка, поле или карточка оформляют своё содержимое сами. Страница не добавляет глобальный класс, без которого другой компонент теряет типографику.

Размеры и координаты конкретной иллюстрации остаются в её scoped SCSS. Общие цвета, интервалы, радиусы, шрифты и длительности берутся из токенов. Inline custom properties используются для значений, которые меняются во время работы: прогресса жеста, положения указателя, индекса столбика.

Для SVG, добавленного через DOM API, `BerryPulse` применяет `:deep` строго под своим host-элементом. Его правила не оформлены глобальными селекторами SVG. SVG-генератор отделён от состояния и жизненного цикла сценария.

## Состояние и действия

- `useOnboardingFlow` создаёт реактивное состояние, контроллер и жест; управляет таймерами и очисткой. `OnboardingFlow` получает функцию длительностей через аргумент. Он не читает CSS сам.
- `useHealthScreen` хранит одно состояние `home | pulse | assistant`, управляет появлением панели и первым запуском графиков. Если пользователь открыл помощника до запуска графиков, таймер отменяется и запускается при возврате.
- `useAssistant` владеет черновиком, вложением, историей и выбором подсказок. `useVoiceInput` отдельно управляет Web Speech API и очищает подписки при закрытии.
- `AssistantComposer` получает `v-model`, состояние и события. Страница не вызывает через ref метод `fill()` внутри дочернего поля.
- `UiBottomSheet` получает `open`, `expanded` и подписи, отдаёт `dismiss`. Его высоту задаёт компоновка страницы. Контрол не открывает помощника самостоятельно.

Ссылки `#home`, `#pulse`, `#assistant` и `#design-system` — переключатели локального превью. Для них достаточно события `hashchange`; маршрутизация приложения не добавлена.

## Данные и графика

`demo-metrics.js` содержит значения для демонстрации макета. Подключение реальных измерений потребует источника данных; в UI и токены API-запросы не добавлены.

Шкала глюкозы представлена `UiDotScale`: контрол получает долю заполнения, число строк и колонок. 128 отдельных SVG-кружков и JSON со списком их имён удалены. Линия веса строится из переданного ряда функцией `buildWeightChart`; изменение измерений меняет геометрию. Цвета графиков берутся из `chart/*`.

Исходная многослойная иллюстрация пульса и блики помощника остаются локальными ассетами. Их названия описывают назначение. Это визуальные материалы из Figma; они не выступают источником состояния приложения.

## Обзор пульса

`PulsePage` собирает `PulseHeart`, `PulseHistory` и `PulseInsight`. `usePulseHistory` рассчитывает точки, интервалы и шкалу времени; компонент истории отвечает за SVG-сетку и доступные кнопки замеров. Цветные точки и интервалы создаются из данных, отдельных SVG для кружков нет.

`UiBottomSheet` анимирует собственную высоту от 642 px до 100% контейнера. Главная остаётся смонтированной, но скрыта через `visibility` и `inert`, поэтому завершённые анимации графиков не перезапускаются. Страница восстанавливает фокус на открывшей карточке.

Сложная иллюстрация из Figma разделена на сердце и сквозную волну. Два прозрачных lossless WebP в масштабе 2x занимают около 162 KB вместо 1.1 MB исходных SVG-градиентов. Значение пульса выводит Vue. CSS-маска ограничивает свет нитями волны. Свет и сердце запускаются в одном кадре с длительностью из SCSS; при закрытии обзора компоненты размонтируются и бесконечные анимации прекращаются.

Источники: [макеты](https://www.figma.com/design/u0EdPHQOmvdQuc7158uN5C/Untitled?node-id=77-4755), [основы](https://www.figma.com/design/u0EdPHQOmvdQuc7158uN5C/Untitled?node-id=237-1893), [цвета](https://www.figma.com/design/u0EdPHQOmvdQuc7158uN5C/Untitled?node-id=251-2346). В приложении: `/#design-system`.

## Цвета

В Figma и SCSS ровно 10 цветовых ролей с режимами Light / Dark:

| Figma       | CSS             |
| ----------- | --------------- |
| Fg          | `--fg`          |
| Bg          | `--bg`          |
| Bg elevated | `--bg-elevated` |
| Border      | `--border`      |
| Accent      | `--accent`      |
| Neutral     | `--neutral`     |
| Success     | `--success`     |
| Warning     | `--warning`     |
| Error       | `--error`       |
| Info        | `--info`        |

Значения находятся непосредственно в `tokens/_color.scss`. Отдельной палитры, оттенков, цветовых переменных компонентов и матриц default/hover/pressed/disabled нет. Контролы используют базовые роли; реакция на нажатие и недоступность оформляется обычным CSS.

`data-theme="light"` и `data-theme="dark"` можно задать на любом контейнере. Графики используют те же роли: Accent для основного ряда, Info для второго, Neutral для подписей, Border для сетки. Прозрачность стекла и интервалов графика задаётся в компоненте.

## Размеры

В `tokens/_markup.scss` оставлены:

- Space: `0, 4, 8, 12, 16, 24, 32, 48`.
- Radius: `4, 8, 12, 16, 24, 32, full`.
- Size: `24, 32, 44, 56` для иконок и контролов.

Значения в компонентах приведены к этой шкале. Алиасы padding/gap/card-radius и единичные радиусы вроде 122 не экспортируются. Геометрия исходной иллюстрации и корпуса телефона остаётся рядом с их стилями.

## Типографика

`tokens/_text-style.scss` содержит семейство, размер, строку и трекинг именованных текстовых стилей. Публичных токенов font-weight нет. Начертание — часть самого стиля; mixin `text.style()` применяет Regular, Medium и Semibold с обычными значениями 400, 500 и 600.

SB Sans Text и SB Sans Display находятся в `public/fonts`, системный стек используется для SF Pro.

## Организация

Общие контролы находятся в `shared/ui`, их SCSS — в `assets/styles/components`. Глобальный `main.scss` подключает токены один раз. Компоненты не добавляют собственные наборы цветовых переменных.

Длительности определены в `tokens/_motion.scss`: CSS использует их напрямую, а `readMotionDuration()` читает те же значения для JavaScript. Тени и размытия определены в `tokens/_effects.scss`. Цвета декоративных иллюстраций и корпуса превью не входят в палитру интерфейса.

## Проверки

`tests/unit/tokens.test.js` проверяет обе темы, точный набор цветовых ролей, разрешение ссылок, компактные шкалы и отсутствие палитры и токенов насыщенности. Браузерные проверки покрывают независимые компоненты в Light/Dark, переходы, графики и уменьшенное движение.

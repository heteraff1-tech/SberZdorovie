# Организация фронтенда

Основа — [Variant/app-new](https://github.com/heteraff1-tech/Variant/tree/main/app-new). Весь исполняемый фронтенд находится в `app/`; корень оставлен для общего README и будущей серверной части.

## Ответственность каталогов

| Каталог                       | Ответственность                                        |
| ----------------------------- | ------------------------------------------------------ |
| `pages`                       | Компоновка экранов, связь событий и управление фокусом |
| `features/*/model`            | Состояние, переходы и подготовка данных                |
| `features/*/ui`               | Разметка функции приложения, props и events            |
| `features/*/config`           | Демонстрационные данные и подписи                      |
| `features/onboarding/lib`     | Рисование кадров существующего SVG                     |
| `shared/ui`                   | Общие контролы, не зависящие от медицинских данных     |
| `shared/composables`          | Общие жесты, ResizeObserver и настройки браузера       |
| `shared/lib`                  | Небольшие функции без состояния экрана                 |
| `components/PhonePreview.vue` | Физическая оболочка превью и её геометрия              |

Внешний код подключает feature через `index.js`. Внутри feature используются относительные импорты. Общий UI не импортирует страницы или features.

## Компоненты и стили

Порядок SFC: `template → script setup → style scoped lang="scss"`. Стили лежат рядом с разметкой в самом компоненте. Общие токены подключаются единожды в `assets/styles/main.scss`.

В `tokens` находятся `color.scss`, `markup.scss`, `text-style.scss` и `effects.scss`. Последний централизует прикладные тени, градиенты и брендинг исходного онбординга без расширения снимка Figma. Координаты иллюстраций, геометрия устройства и длительности сцен остаются локальными. Margin, padding и gap в features/pages используют общую шкалу.

`MetricCard`, `MetricValue` и `DotScale` относятся к `features/health/ui`. `SuggestionCard` относится к помощнику. В `shared/ui` остались кнопки, иконки, штора и нижняя навигация.

## Сценарии

`HomePage` собирает показатели и статическую композицию помощника. `useHealthScreen` хранит одно состояние `home | pulse | assistant`. `PulseOverview` — содержимое раскрытой шторы; он не импортирует другую страницу.

`App` показывает панель `PulseEntry` после первого раскрытия показателей и окончания перехода онбординга. Панель стоит справа от корпуса на широких экранах и под ним на узких. Режим `?mobile=1` открывает только полноэкранное превью. `usePulseMeasurements` сохраняет числовые значения и отметки времени в localStorage. Те же записи доступны из формы в обзоре пульса, обновляют последнее значение на главной и дополняют историю. Подробнее в [правилах записи пульса](pulse-rules.md).

`useOnboardingFlow` связывает Vue и два независимых класса: `PullGesture` вычисляет жест, `OnboardingFlow` меняет состояние и рассчитывает движение. `PulseShape` только рисует геометрию SVG.

`readMotionDuration(name, element)` читает CSS-переменную на корне конкретного экрана. Поэтому JavaScript и локальная анимация используют одинаковую длительность. Таймеры, подписки и кадры очищаются при уходе с экрана.

## Граница помощника и медицинского сценария

У помощника нет модели сообщений, файлового input, Speech API и обработчиков движения указателя. Карточки и верхние значки отображаются обычной разметкой. Поле сообщения — статичный блок. Нижняя навигация и переходы между экранами принадлежат `HomePage`. Команд выбора симптомов и медицинских ответов в UI нет. `getAssistantResponse` сохранён как изолированный модельный контракт с unit-тестами для будущей интеграции. Крестик `AssistantHeader` использует `UiIconButton` и событие close; `HomePage` возвращает показатели и фокус. Заголовок постоянно находится в DOM, его CSS-свойства анимируются без замены узла.

## Передача разработчикам

Публичные функции описаны в [functions.md](functions.md), короткие комментарии стоят у объявлений. Источники будущих API-данных заменяются в моделях; расчёт графиков и компоненты остаются независимыми от транспорта.

## Harness

Корневой [AGENTS.md](../../AGENTS.md) задаёт правила. `tests/lib/source-inspection.js` разбирает Vue/JavaScript/SCSS через AST, разрешает alias и относительные импорты, проверяет стили и сообщает строки нарушений. Направление импортов: `pages → features → shared`; разные features независимы, страница подключает их публичные index. `tests/e2e/fixtures.js` автоматически собирает ошибки JS/консоли и проверяет ширину документа.

После изменения кода обязательна команда `npm run qa` из app: unit → build → Playwright. Та же команда используется в GitHub Actions. Датчики проверены собственными отрицательными примерами; отключать их или обновлять визуальные эталоны без объяснения запрещено.

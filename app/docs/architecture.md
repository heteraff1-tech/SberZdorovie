# Организация фронтенда

Основа — [Variant/app-new](https://github.com/heteraff1-tech/Variant/tree/main/app-new). Весь исполняемый фронтенд находится в `app/`; корень оставлен для общего README и будущей серверной части.

## Ответственность каталогов

| Каталог                       | Ответственность                                        |
| ----------------------------- | ------------------------------------------------------ |
| `pages`                       | Компоновка экранов, связь событий и управление фокусом |
| `features/*/model`            | Состояние, переходы и подготовка данных                |
| `features/*/ui`               | Разметка функции приложения, props и events            |
| `features/*/config`           | Демонстрационные данные и подписи                      |
| `features/onboarding/lib`     | Рисование кадров существующего SVG                     |
| `shared/ui`                   | Общие контролы, не зависящие от медицинских данных     |
| `shared/composables`          | Общие жесты, ResizeObserver и настройки браузера       |
| `shared/lib`                  | Небольшие функции без состояния экрана                 |
| `components/PhonePreview.vue` | Физическая оболочка превью и её геометрия              |

Внешний код подключает feature через `index.js`. Внутри feature используются относительные импорты. Общий UI не импортирует страницы или features.

## Компоненты и стили

Порядок SFC: `template → script setup → style scoped lang="scss"`. Стили лежат рядом с разметкой в самом компоненте. Общие токены подключаются единожды в `assets/styles/main.scss`.

В `tokens` три обычных SCSS-файла: `color.scss`, `markup.scss`, `text-style.scss`. Параметры сцен, геометрия устройства, тени и локальные задержки находятся у владельца компонента. Их нет в глобальном каталоге дизайн-системы.

`MetricCard`, `MetricValue` и `DotScale` относятся к `features/health/ui`. `SuggestionCard` относится к помощнику. В `shared/ui` остались кнопки, иконки, штора и нижняя навигация.

## Сценарии

`HomePage` собирает показатели и статическую композицию помощника. `useHealthScreen` хранит одно состояние `home | pulse | assistant`. `PulseOverview` — содержимое раскрытой шторы; он не импортирует другую страницу.

`useOnboardingFlow` связывает Vue и два независимых класса: `PullGesture` вычисляет жест, `OnboardingFlow` меняет состояние и рассчитывает движение. `PulseShape` только рисует геометрию SVG.

`readMotionDuration(name, element)` читает CSS-переменную на корне конкретного экрана. Поэтому JavaScript и локальная анимация используют одинаковую длительность. Таймеры, подписки и кадры очищаются при уходе с экрана.

## Граница статического помощника

У помощника нет модели сообщений, файлового input, Speech API и обработчиков движения указателя. Карточки и верхние значки отображаются обычной разметкой. Поле сообщения — статичный блок. Нижняя навигация и переходы между экранами принадлежат `HomePage`.

## Передача разработчикам

Публичные функции описаны в [functions.md](functions.md), короткие комментарии стоят у объявлений. Источники будущих API-данных заменяются в моделях; расчёт графиков и компоненты остаются независимыми от транспорта.

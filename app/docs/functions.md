# Указатель функций

Все пути ниже отсчитываются от `app/src`. У объявлений стоят короткие комментарии. Таблицы помогают найти нужный участок перед переносом кода.

## Экран здоровья

| Файл / функция                                                                      | Назначение и входные данные                                                                                  |
| ----------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `features/health/model/useHealthScreen.js` — `useHealthScreen(initialView, screen)` | Возвращает состояние экрана и действия перехода. `screen` — ref корня для чтения локальной задержки графиков |
| `startCharts()`                                                                     | Планирует один запуск графиков; готовую анимацию не повторяет                                                |
| `openAssistant() / closeAssistant()`                                                | Переключает помощника и показатели                                                                           |
| `openPulse() / closePulse()`                                                        | Раскрывает и сворачивает обзор в существующей шторе                                                          |
| `useGlucoseScale(data)`                                                             | Получает функцию чтения данных и возвращает форматированное число и долю заполнения                          |
| `buildWeightChart(days, options)`                                                   | Возвращает точки, линию и заливку. Параметры задают область графика и диапазон значений                      |
| `usePulseHistory(source)`                                                           | Возвращает выбранный период, замер, точки и подписи оси                                                      |
| `minutes(time)`                                                                     | Переводит HH:MM в минуты                                                                                     |
| `getX(time) / getY(value)`                                                          | Переводит время и пульс в координаты области графика                                                         |

## Компоновка HomePage

| Функция                 | Назначение                                                              |
| ----------------------- | ----------------------------------------------------------------------- |
| `showAssistant()`       | Открывает помощника и фокусирует корень экрана для Escape               |
| `showPulse(event)`      | Открывает обзор и сохраняет кнопку, на которую нужно вернуть фокус      |
| `hidePulse()`           | Сворачивает обзор и восстанавливает фокус                               |
| `hideAssistant()`       | Закрывает помощника крестиком, навигацией или Escape и возвращает фокус |
| `handleEscape()`        | Возвращает из текущего вложенного экрана                                |
| `navigate(destination)` | Обрабатывает нижнюю навигацию                                           |

## Онбординг

| Файл / функция                                                         | Назначение                                                               |
| ---------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `model/useOnboardingFlow.js` — `useOnboardingFlow(onComplete, screen)` | Соединяет Vue, контроллер этапов, жест и настройки уменьшенного движения |
| `startPull(event)`                                                     | Захватывает основной указатель и учитывает масштаб макета                |
| `movePull(event)`                                                      | Передаёт прогресс и скорость жеста в модель                              |
| `endPull(event, cancelled)`                                            | Завершает подключение либо возвращает фигуру                             |
| `advance() / finish()`                                                 | Передаёт нажатие кнопки или клавиши контроллеру                          |

`model/OnboardingFlow.js` получает реактивное состояние и две функции: чтение reduced motion и чтение длительности.

| Метод класса              | Назначение                                 |
| ------------------------- | ------------------------------------------ |
| `start()`                 | Запускает вступление и приветствие         |
| `advance()`               | Переключает шаги и штору                   |
| `canPull`                 | Проверяет, доступен ли жест                |
| `grab()`                  | Перехватывает текущую анимацию             |
| `setPull(value, speed)`   | Меняет цель движения и импульс             |
| `release()`               | Возвращает фигуру после короткого жеста    |
| `finish(speed)`           | Завершает слияние и переводит экран в done |
| `dispose()`               | Очищает таймер и кадр                      |
| `#after(duration, run)`   | Планирует следующий шаг                    |
| `#stopFrame()`            | Отменяет текущий requestAnimationFrame     |
| `#follow(target, spring)` | Рассчитывает затухающую пружину            |
| `getImpulse(speed)`       | Ограничивает резкий импульс                |

`model/PullGesture.js` не меняет DOM и возвращает результат расчёта жеста.

| Метод                           | Назначение                                                   |
| ------------------------------- | ------------------------------------------------------------ |
| `start(event, scale, progress)` | Начинает отслеживание указателя                              |
| `move(event)`                   | Возвращает прогресс и сглаженную скорость                    |
| `end(event, cancelled)`         | Определяет завершение; отменённый жест не считается успешным |
| `#distance(event)`              | Считает смещение от начала жеста                             |

## SVG-рендерер

`features/onboarding/lib/PulseShape.js` работает с уже загруженным SVG.

| Метод / функция                  | Назначение                                            |
| -------------------------------- | ----------------------------------------------------- |
| `new PulseShape(svg)`            | Сохраняет исходные пути, кольца и нити                |
| `draw(pull, merge)`              | Рисует кадр по прогрессу вытягивания и слияния        |
| `#drawThreads(...)`              | Перестраивает нити в системе координат SVG            |
| `getRing(ring)`                  | Подготавливает пути кольца и блик                     |
| `mix(from, to, progress)`        | Линейно смешивает значения                            |
| `getCurve(points)`               | Собирает замкнутую гладкую кривую                     |
| `BerryPulse.vue — readContact()` | Считает близость нитей к сердцу для свечения логотипа |

## Медицинский сценарий HC-001

| Файл / функция                                                                       | Назначение и контракт                                                                                                                           |
| ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `features/assistant/model/healthcareGuardrail.js` — `getAssistantResponse(symptoms)` | Возвращает предупреждение только при highPulse=true и discomfort=true либо dizziness=true. Иначе null. Не ставит диагноз и не назначает лечение |
| `shared/ui/UiButton.vue` — `handleClick(event)`                                      | Не открывает заблокированную ссылку и не испускает click; href включает нативный anchor                                                         |

## Датчики QA

Пути в этой таблице отсчитываются от `app/`.

| Файл / функция                                              | Назначение                                                                                  |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| `tests/lib/source-inspection.js` — `sourceFiles(directory)` | Собирает исходники без симлинков                                                            |
| `importsIn(source, file)`                                   | Извлекает зависимости JS/TS/Vue/SCSS, включая export-from, require и literal dynamic import |
| `architectureViolations(source, file)`                      | Разрешает пути и возвращает нарушения границ FSD с инструкциями                             |
| `tokenNames()`                                              | Читает общие переменные tokens для проверки spacing                                         |
| `styleViolations(source, file, names)`                      | Возвращает сырые цвета и отступы вне общей шкалы с номерами строк                           |
| `tests/e2e/fixtures.js` — `observeBrowserErrors(page)`      | Подписывается на pageerror/console.error; возвращает список и dispose                       |
| `expectNoHorizontalOverflow(page)`                          | Проверяет scrollWidth документа относительно innerWidth                                     |

Внутренние helpers `blocks`, `visit`, `importPath`, `rawColors` соответственно разбирают SFC, обходят AST, разрешают Vite/relative пути и находят цветовые литералы, сохраняя ссылки на SVG.

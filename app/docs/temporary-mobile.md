# Временный мобильный просмотр

Включение: `?mobile=1` **до** hash, например `/?mobile=1#home`. Без параметра используется прежний `PhonePreview`. Режим рассчитан прежде всего на портретный просмотр в Android Chrome, включая Xiaomi 14T; модель устройства не определяется по User-Agent.

## Изоляция

- `src/components/temporary-mobile/TemporaryMobilePreview.vue` — единственная временная оболочка: viewport без корпуса, safe area, кнопка fullscreen и локальные адаптации макета.
- `useMobilePreview.js` — ResizeObserver, масштаб ширины 402 px, логическая высота и Fullscreen API. Подписки очищаются при размонтировании.
- `App.vue` выбирает оболочку по параметру. Страницы, бизнес-модели и стандартный PhonePreview не изменяются.
- `index.html` содержит viewport-fit=cover для аппаратных safe area.

`measure()` переводит размер области браузера в логические координаты макета. `enterFullscreen()` вызывается только по нажатию; отказ API отображается через role=status. `updateFullscreen()` возвращает кнопку после системного выхода. Состояние и стили принадлежат временному адаптеру.

На низком viewport высота обычной шторы ограничена свободной областью под заголовком; карточки доступны внутренней прокруткой. Развёрнутая штора пульса занимает всю область. Иллюстрации помощника уменьшаются в свободном центре, CTA онбординга привязан к нижнему краю. Искусственные статус-бар, вырез и HomeBar скрыты.

## Быстрое удаление

1. В `App.vue` верни `<PhonePreview :light="home">…</PhonePreview>` вместо динамического component.
2. Удали импорт TemporaryMobilePreview, константу mobilePreview, привязку app-stage--mobile и её CSS-блок.
3. Удали каталог `src/components/temporary-mobile/` и `tests/e2e/mobilePreview.spec.js` вместе с этим документом и разделом README. viewport-fit=cover можно оставить: это общий параметр мобильного браузера.
4. Запусти `npm run qa` из app.

## Проверка

`mobilePreview.spec.js` проверяет области 393×873 и 412×915, изменение высоты до 700 px, отсутствие рамки и переполнения, навигацию, штору пульса, доступность нижних карточек, вход/выход Fullscreen API и онбординг. Общий fixture контролирует ошибки JS и консоли.

Эмуляция viewport не равнозначна тесту на физическом Xiaomi. Реальная возможность скрыть браузерные панели зависит от Chrome и разрешения Fullscreen API; режим без рамки работает независимо от него.
